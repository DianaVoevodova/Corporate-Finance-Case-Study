# Corporate-Finance-Case-Study
Консолидированная финансовая модель ГК: план-факт 2024 и стратегия 2025-2029


## 📌 Описание проекта
Разработка комплексной финансовой модели Группы компаний, включающей ретроспективный план-факт анализ за 2024 год и долгосрочное прогнозирование до 2029 года. 
Реализован полный цикл консолидации финансовой отчетности, включая элиминацию внутригрупповых оборотов и расчет инвестиционных корректировок при сделках по приобретению бизнеса.


## 🛠 Ключевой функционал:

### 1. План-факт анализ (2024)
- Три основные формы: ОПУ (P&L), ОДДС (Cash Flow), УБ (Balance Sheet).
- Автоматизированный расчет отклонений и анализ причин расхождения финансовых показателей.
- Консолидация данных по нескольким юридическим лицам внутри группы.

### 2. Долгосрочное планирование (2025–2029)
- Построение прогнозных моделей ОПУ, ОДДС и Баланса для каждого юнита.
- Консолидация Группы: Cбор данных дочерних компаний в единый мастер-бюджет.
- Расчет прогнозных финансовых коэффициентов (рентабельность, ликвидность, автономность).

### 3. Блок M&A и Консолидация (МСФО принципы)
- **Элиминация ВГО**: Автоматизированное исключение внутригрупповых оборотов и взаимных обязательств для формирования корректного финансового результата Группы.
- **Гудвил**: Расчет стоимости деловой репутации при покупке доли компании.
- **Неконтролирующая доля (НД)**: Выделение доли миноритариев в капитале и прибыли.
- **Собственный капитал**: Расчет консолидированной нераспределенной прибыли холдинга с учетом процента владения.
